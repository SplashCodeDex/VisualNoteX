## 🚀 Getting Started

### Prerequisites
```bash
# Install Rust (if not already installed)
# Windows: Download from https://rustup.rs
cargo --version  # Should show 1.89.0 or later
```

### Development Setup
```bash
# Install dependencies
npm install

# Start development server
npm run tauri:dev

# Build production version
npm run tauri:build
```
