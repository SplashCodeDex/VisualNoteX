## 🚀 Getting Started

### Prerequisites
```bash
# Install Rust (if not already installed)
# Windows: Download from https://rustup.rs
# macOS/Linux: Use rustup installer
cargo --version  # Should show 1.89.0 or later

# Install Node.js 18+
node --version   # Should show 18.0.0 or later
npm --version    # Should show 9.0.0 or later
```

### Development Setup
```bash
# Clone the repository
git clone https://github.com/SplashCodeX/visualplanx.git
cd visualplanx

# Install dependencies
npm install

# Start development server (Web)
npm run start

# Start development server (Desktop)
npm run tauri:dev

# Build production version (Web)
npm run build:web

# Build production version (Desktop)
npm run tauri:build

# Run performance tests
npm run test:performance
```

### Performance Monitoring
```bash
# Access performance dashboard (available in development)
# Open http://localhost:7200
# Performance dashboard appears in bottom-right corner

# Run automated performance tests
npm run test:performance

# Generate performance report
npm run test:report
```
